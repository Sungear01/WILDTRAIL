# Agent Execution Rules & Autonomous Mode

## Autonomous Execution Guidelines
- **Minimize user interruptions**: Proceed autonomously with coding, debugging, and task execution. Do not ask for confirmation on standard tasks or trivial decisions.
- **Auto-run & Dev Server**: When asked to run local servers, builds, or tests, execute them directly without waiting for manual confirmation.
- **Complete Solutions**: Provide full working implementations and edits directly to files.
